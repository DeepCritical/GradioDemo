## 🚀 What It Does

DeepCritical is a **Deep Research Agent** specialized in drug repurposing. It doesn't just "search Google"; it acts as a tireless research assistant that:

1.  **Orchestrates Multi-Source Retrieval**: Simultaneously mines **PubMed**, **ClinicalTrials.gov**, and **EuropePMC** (bioRxiv/medRxiv) for peer-reviewed and preprint data.
2.  **Thinks & Reasons**: Uses a "Judge-Evaluator" loop to assess evidence quality. If the data is insufficient, it autonomously generates new search queries and digs deeper.
3.  **Executes Code**: Writes and runs statistical analysis code in a secure **Modal Sandbox** to verify findings quantitatively.
4.  **Connects Everywhere (MCP)**: Implements the **Model Context Protocol**, meaning you can use DeepCritical's specialized tools directly inside your existing AI workflows (like Claude Desktop).

## 💡 What We Learned

Building DeepCritical taught us that **structure is everything**.
* **Type Safety in Agents**: Moving from unstructured prompts to `Pydantic` models transformed our agents from "chatbots" into reliable "research tools."
* **The Power of MCP**: We learned that by adhering to open standards like MCP, we didn't have to build a custom frontend for every use case. We built the tools once, and they work in Gradio, Claude Desktop, and terminal clients instantly.
* **Stateful Graphs**: Managing the state of a deep research loop (Search -> Judge -> Loop -> Synthesize) required moving beyond simple chains to stateful graph architectures.

## 🎥 Features Roadmap

### Completed ✅
- [x] **Multi-Source Search Engine**: Aggregated biomedical search (PubMed + ClinicalTrials + EuropePMC).
